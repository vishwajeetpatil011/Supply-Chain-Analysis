# 📦 Supply Chain Analysis

## 📌 Project Overview

The **Supply Chain Analysis** project is an end-to-end Business Intelligence project designed to analyze supply chain operations and generate meaningful insights using **Excel, SQL, Power BI, and Tableau**.

The project focuses on understanding order fulfillment, inventory management, procurement costs, transportation performance, and key supply chain KPIs through interactive dashboards.

The goal is to transform raw supply chain data into actionable business insights that support data-driven decision-making.

---

## 🎯 Business Objectives

- Analyze order and sales performance.
- Track inventory levels and reorder status.
- Understand procurement and transportation costs.
- Monitor delivery performance and fulfillment rates.
- Build interactive dashboards for business users.
- Generate insights to improve supply chain efficiency.

## 📊 Dashboard Features

### 📦 Order & Sales Analysis
- Total orders and sales revenue.
- Average Order Value (AOV).
- Orders by region, country, and city.

### 🏭 Inventory Management
- Stock on hand tracking.
- Reorder status and reorder percentage.
- Inventory turnover ratio.

### 🚚 Transportation & Delivery
- On-time delivery percentage.
- Average delay in days.
- Ship mode utilization.

### 💰 Cost Analysis
- Procurement cost.
- Transportation cost.
- Total supply chain cost and cost per unit.

---

## 📈 Key KPIs Analyzed

- Total Orders & Sales Revenue
- Average Order Value (AOV)
- Inventory Turnover Ratio & Stock on Hand
- Reorder Percentage

- Total Supply Chain Cost & Cost per Unit

## 🚀 How to Use This Project

### 1. Clone Repository
```bash
git clone https://github.com/vishwajeetpatil011/Supply-Chain-Analysis.git
```

### 2. View the Dashboards
- **Power BI**: Open `Power_BI/power BI dashboard.pbix` in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
- **Tableau**: Open `Tableau/tableau dashboard.twbx` in [Tableau Reader](https://www.tableau.com/products/reader) or Tableau Desktop.
- **Excel**: Open `Excel/excel dashboard.xlsx` in Microsoft Excel.
- **SQL**: Review `Sql/sql.sql` for the queries used to derive each KPI.
