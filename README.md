# Supply Chain Analysis

An end-to-end supply chain analytics project covering order fulfillment, inventory, procurement, transportation, and delivery performance — built with SQL, Excel, Power BI, and Tableau.

## 📁 Project Structure

| File | Description |
|---|---|
| `excel dashboard.xlsx` | Cleaned and structured source dataset (orders, inventory, warehouse dimensions) |
| `sql.sql` | SQL queries for KPI calculations — total orders, revenue, AOV, inventory turnover, on-time delivery %, fill rate, backorder rate, forecast accuracy, and more |
| `power BI dashboard.pbix` | Power BI dashboard for interactive exploration of supply chain KPIs |
| `tableau dashboard.twbx` | Tableau packaged workbook (same analysis, Tableau version) |

## 📊 Key Metrics Covered

- Total Orders & Sales Revenue
- Average Order Value (AOV)
- Inventory Turnover Ratio & Stock on Hand
- Reorder Status / Reorder Percentage
- Procurement & Transportation Cost
- Total Supply Chain Cost & Cost per Unit
- On-Time Delivery % and Average Delay
- Ship Mode Utilization
- Forecast Accuracy, Fill Rate, and Backorder Rate

## 🛠️ Tools Used

- **SQL** — KPI calculation and data querying
- **Excel** — Data cleaning and structuring
- **Power BI** — Interactive dashboard
- **Tableau** — Interactive dashboard (alternate visualization)
- **PowerPoint** — Insights and executive summary

## 🚀 How to View

- **Power BI**: Open `power BI dashboard.pbix` in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
- **Tableau**: Open `tableau dashboard.twbx` in [Tableau Reader](https://www.tableau.com/products/reader) or Tableau Desktop.
- **SQL**: Review `sql.sql` for the queries used to derive each KPI.
